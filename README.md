# Cache Desk

**Windows cleanup and thumbnail previews · Made by Wunet**

Cache Desk lets you review selected Windows caches, preview supported cached pictures, open their file locations, and choose which files to delete.

## Download

[Download from Releases](../../releases/latest)

Choose `CacheDesk-1.1.0-win-x64.zip`, extract it, then open `CacheDesk.exe`. The accompanying `SHA256SUMS.txt` contains the ZIP checksum. The automatically generated “Source code” archives contain this distribution repository's documents, not the application.

Requires Windows 10/11 x64 with .NET Framework 4.8 or later. The current executable is unsigned.

## Features

- Thumbnail-cache previews for supported PNG, JPEG, and BMP entries, with paging and larger views.
- Selection and confirmation before deleting thumbnail caches, old temporary files, recent shortcuts, and Jump Lists including pins.
- File-location and category-folder shortcuts.
- User mode and administrator mode through Windows' normal UAC flow.
- Saved Wi-Fi profile removal and shortcuts to Windows clipboard, device, storage, and Explorer tools.
- Version and maker information in About.

The gallery is read-only and does not export pictures. Cache IDs do not establish original filenames or whether an original was deleted. Cleanup bypasses the Recycle Bin and is not secure erasure.
